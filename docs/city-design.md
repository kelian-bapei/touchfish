# 山地河谷科创城市 · 数字孪生交互方案

- 版本：v0.2（2026-11-24）
- 文档性质：可迭代设计基线。后续每次"新增 / 删除 / 修改"都在本文件内累积，由 git 记录历史，可回滚到任意版本。
- 目标引擎：UE5.4（第一目标），Unity HDRP 作为移植目标保留；选型与实施路线见 §0.1、§0.2。

## 0. 全局约定

**尺度与坐标**：城市范围 4.2 km（东西）× 3.0 km（南北），UE 单位 cm；原点取跨河大桥中心线与北岸滨河大道交点；EL 0.00 = 河流常水位。
**风格**：写实 PBR，华北山地新城 + 现代科技园区；不做卡通化，不做过量霓虹，不使用奇幻植被。
**性能目标**：1080p / 60 fps（RTX 3060 级，Lumen 中档）；1440p / 60 fps（4070 级）；另设低配降级档。
**节点 ID**：`CAM-*` 相机、`OBJ-*` 物件、`ENV-*` 全局、`EVT-*` 事件、`EXT-*` 预留。**ID 一旦分配永不改变**，后续增删改均以 ID 定位。
**状态分层**：L0 静态场景 / L1 全局环境（时间、天气、车流）/ L2 物件局部（灯、水位、弹窗）/ L3 事件（汛期、夜景）。优先级 L3 > L1 > L2；相机独立，不被环境锁。
**数据驱动**：所有交互点由 `DT_InteractionNodes` 表驱动（ID、类型、参数、文案、目标 Actor），蓝图只做路由；增删交互不改逻辑代码。

### 0.1 选型结论（已定，2026-11-24）

|---|---|---|

## 1.2 地形与山体

- 高度图 4096×4096（≈1 m/像素）。谷底 EL 0，北山脊 +220 m，南山 +140 m，河床 -3 m；河谷为 V 形剖面，两侧坡度渐变。
- 程序化基底（噪声 + 河谷剖面）上手工雕出 4 块台地：园区 +4、广场 +2.8、居住 +3.5、绿心 +2.2；台地间 1:3 放坡，边缘用模块化挡土墙 / 护坡（4 m、8 m 两种段件）。
- 网格：8×8 chunk，LOD0–3，总面数 ≤300k；远山单独低模背景（2k tris）+ 雾遮蔽。
- 细节密度：只对步道、广场、观景台周边精雕；山体其余部分靠岩石 decal + PCG 散布。
- 河岸两级亲水平台：EL +0.8 / +1.6，石材铺装，配跌级踏步。

## 1.3 水系与河岸

- 河道中心线 spline，宽 90–140 m，深 3–5 m；水面每 200 m 一段（2k tris/段），双层 UV 滚动法线表现流动。
- 参数化水位：`WaterLevel` 常态 0.00、汛期 +2.40；流速 `FlowSpeed` 常态 0.8 m/s、汛期 2.5 m/s。全部由材质参数集合（MPC）统一驱动，确保全河段同步。
- 岸线三种做法：广场 / 园区段硬质驳岸（石材模块）、绿心段生态缓坡（芦苇、湿生植物）、3 处亲水平台。
- 滨河栏杆：高 1.1 m，2 m 一段分段模块化；3 处挂彩色控制牌（EL +1.4），作为 OBJ-03 交互点。
- 漫滩区：绿心段预留约 6000 m² floodplain 网格，地面 EL 2.10–2.30；汛期水位 2.40 时被淹 0.1–0.3 m，即"漫滩"可见效果。
- 桥下：水位标尺贴图（0–3 m 刻度），桥墩防撞标识与检修通道。

## 1.4 建筑

三级资产：

- **地标（1 座）**：科创大楼，78 m / 18F / 32×32 m 塔楼，玻璃幕墙 + 竖向遮阳鳍，顶部设备层与航空障碍灯；45k tris，4K trim sheet；夜间内透窗格 + 顶部灯带。
- **中型（约 10 座）**：研发楼×2（24 m、5F）、数据中心（16 m、4F，重设备轻开窗）、展示中心（2F 大跨玻璃）、市民中心（4F，石材 + 玻璃）、住宅×8（6–18F）、商业街（2F 连廊）；每座 8k–20k tris，共享 2 套立面模块 + 3 套材质。
- **背景（12 座）**：山脚 / 远景楼群，2k–5k tris，房间贴图，合并为 HLOD。

模块化套件（Kit）：3 m×3.6 m 开间、转角件、女儿墙、裙房、屋顶设备、入口雨棚。楼体 = 模块堆叠 + 局部 unique 细节（入口、Logo、雨棚）。**不做室内**，内透仅用窗格 emissive + 少量室内盒体灯。

## 1.5 路网与交通设施

- 等级：快速路（北环，双向 6 车道，60 km/h）、主干路（南北岸滨河大道、科创大道、城市主轴，40–50 km/h）、次干路（20–30 km/h）、支路 + 园区内部路、慢行道（3–5 m 步道 + 2.5 m 自行车道）。
- 跨河大桥：双塔斜拉，主跨 280 m，桥面宽 28 m（4 车道 + 2 人行道），塔高 62 m，斜拉索 2×12 对，桥面 EL +16 m，通航净空 12 m。
- 高速出入口：收费站 6 闸（3 进 3 出），收费棚 18×24 m，喇叭形匝道汇入北环；两侧退让绿带。
- 交叉口：信号灯（红绿循环 30 s，与车流联动）、斑马线、导流岛；标线以 decal 为主，减速带 / 导向箭头用 mesh。
- 停车：园区地面停车位 + 地下车库入口（坡道 + 卷帘门，静态）。

## 1.6 植被

- 温带落叶阔叶。树种：国槐、白蜡、银杏、元宝枫、油松、侧柏；湿地补芦苇、香蒲。无热带 / 奇幻树种。
- 树木 5 种 × 3 尺寸：LOD0 4k–6k tris、LOD1 1.2k、LOD2 300、150 m 外 impostor；全城 8k–12k 株，HISM / PCG 散布。
- 灌木花境 20 组，每组 300–800 tris，近景 200 丛；草地不做逐草实例，4 层混合 shader（草坪 / 枯草 / 泥土 / 落叶）+ 5 m 内少量草卡片。
- 行道树统一 8 m 间距，树池模块化；滨河步道内侧种植垂柳列。
- 山体背景林用 impostor 群 + 远山卡片，不逐棵摆放。

## 1.7 路灯与小品

- 路灯 3 种：主干道 10 m 双臂、次干道 8 m 单臂、步道 4 m 庭院灯；全城约 180 盏，全部可交互（状态存于 Actor）。
- 小品：长椅、垃圾桶、公交站×2、自行车架、护栏、亲水平台、雕塑×1（广场，抽象几何）、旗杆、桥名牌、水位标尺、电子指示屏（静态贴图，预留数据接口）。
- 全部模块化、4 m 网格对齐，便于 PCG 与批量摆放。

## 1.8 灯光与天空

- 日间：动态 Directional Sun + Virtual Shadow Maps、SkyLight、SkyAtmosphere、低精度 Volumetric Cloud。
- 夜间：月光（冷色、低强度）、路灯（spot + IES，仅近景 8–12 盏投影，其余 emissive）、建筑内透、霓虹灯带（emissive + bloom）、车灯。
- 所有灯光参数进入 MPC，由时间预设与 Level Sequence 插值，过渡 2–3 s。
- 雾：高度雾，基础 0.015，雨天 / 汛期 0.03，薄雾天 0.04；颜色随时段。
- 后期：固定手动曝光、夜间 bloom 0.8、轻暗角；不做重度调色，保持写实。

## 1.10 面数分级与性能预算

- 总三角面：≤9M（开 Nanite），关 Nanite ≤4M；可见 draw call ≤2500；单帧 GPU ≤16 ms。
- 分区：地形 300k、建筑 1.5M、植被 3M（含 impostor）、道路桥 400k、家具 300k、车辆行人 200k。
- LOD：建筑 3 级 + HLOD（LOD0 100% / LOD1 35% / LOD2 8% / HLOD 3%）；桥 2 级；植被 4 级。
- 流送：World Partition，256 m 单元格，HLOD 2 层，纹理流送池 4 GB。
- 降级档：关 Lumen 反射、关体积云、雨粒子减半、阴影距离 80 m、车流 40 辆、行人 60。
- Nanite 范围：建筑、桥体、地形崖壁等 hero 资产启用；植被、小品、半透明一律走 LOD + impostor，禁用 Nanite。

## 1.11 贴图与材质规范

- PBR：BaseColor（sRGB）、ORM 打包（R=AO / G=Roughness / B=Metallic）、Normal DX 8-bit。
- 分辨率：hero 4K、mid 2K、props 1K、远景 512；trim sheet 4K 共享（建筑立面、道路、栏杆）。

# 第二部分 · 可交互逻辑清单

节点索引：CAM-01～05 / OBJ-01～04 / ENV-01～03 / EVT-01～02 / EXT-01～05。

## 2.0 通用交互框架

- 拾取：鼠标左键点击，射线检测 `Interactable` 通道，300 m 内有效（鸟瞰下也可点，便于演示）。
- 悬停：光标变手型，物体 custom depth 高亮（描边），底部提示条显示"点击查看 / 操作"。
- 弹窗：UMG，同一时刻只开一个，ESC 或点空白处关闭，不暂停相机。
- 状态：`IInteractable` 接口（`GetId` / `GetLabel` / `OnActivate` / `OnDeactivate` / `SerializeState`），全局 `BPC_InteractionRouter` 单例路由。
- 冲突优先级：EVT > ENV > OBJ；事件激活时可置灰相关按钮并给一句提示，而不是静默失败。
- 可导出交互状态 JSON，便于复现截图或做演示脚本。

## 2.1 相机交互

**CAM-01 自由漫游**
- 触发：点击"进入漫游"后激活（产品看板为初始形态，不自动启用）；WASD + QE 升降，右键拖拽视角，Shift 加速。
- 反馈：三档速度 3 / 10 / 30 m/s；步行模式（身高 1.7 m、重力、碰撞）与飞行模式（无碰撞）一键切换。
- 边界：限制在 4.2×3.0 km + 400 m 空域内；不得穿入山体。

**CAM-02 定点鸟瞰**
- 触发：进入场景时的**默认相机**（产品看板形态）；UI 按钮可重新呼出，从漫游返回时回到最近一次鸟瞰预设。三个预设：全城（正交相机，OrthoWidth 4600、高度 EL +600 m）、河谷轴测（沿河、俯角 30°）、园区局部。
- 反馈：2.5 s 平滑插值（含曝光；正交预设插值宽度、透视预设插值 FOV），到位后可绕目标轨道旋转（半径 300 m）。
- 退出：ESC 或"自由漫游"按钮。

**CAM-03 快速点位跳转**
- 触发：UI 列表或快捷键 1–3。
- 目标：科创大楼（EL +90 m、正立面 120 m 外）、滨河步道（EL +2 m、沿河斜 45°）、山顶观景台（EL +145 m、俯视河谷）。
- 反馈：1.8 s 样条飞行 + 0.15 s 短黑场 + 目的地名称 toast；落地自动转自由漫游。
- 冲突：跳转时自动关闭弹窗。

**CAM-04（预留）** 跟随车流巡游；**CAM-05（预留）** 无人机航点自动巡航。

## 2.2 物件点击交互

**OBJ-01 科创大楼**
- 触发：点击楼体任意面（悬停整栋高亮）。
- 反馈：三页签弹窗：
  1. 简介：名称、定位、入驻企业示例；
  2. 楼层功能：B1 车库 / 1F 展厅 / 2–5F 研发 / 6–9F 实验室 / 10–14F 办公 / 15–17F 配套 / 18F 设备层；
  3. 能耗：当日用电 kWh、分项（空调 / 照明 / IT / 电梯）、24 h 折线，可切周 / 月。
- 附加：弹窗打开期间楼体轮廓灯增强；数据标注"演示数据"。

**OBJ-02 路灯**
- 触发：点击灯柱（300 m 内），悬停高亮灯头。
- 反馈：立即 toggle 开关（0.3 s 亮度过渡），弹窗含状态、亮度滑条 0–100%（默认 80%、色温 4000 K）、所属路段。
- 边界：连点只更新状态；被手动改过的灯，在夜景模式下保持用户设置，其余灯随事件点亮。

**OBJ-03 滨河栏杆点位（3 处：广场段 / 绿心段 / 居住区段）**
- 触发：点击彩色控制牌或栏杆本体。
- 反馈：弹窗显示当前水位、流速、状态；按钮 [常态] / [汛期]；切换后水位 2.5 s 插值、流速同步、水色变浑、漫滩区注水、桥下水位尺上升、栏杆警示灯黄转红、水声增强。
- 联动：3 个点位共享同一全局水位状态；与 EVT-01 共用状态机。灾害流程被触发时，点位只允许"恢复常态"。

**OBJ-04 公园信息牌（3 块：绿心北入口 / 湿地栈道 / 广场）**
- 触发：点击牌面。
- 反馈：图文弹窗（概览 / 湿地生态 / 植物科普，2–3 段 + 示意图），底部"定位"按钮把相机飞到牌前。
- 夜间：牌面 emissive 自发光，保持可读。

## 2.4 事件交互

**EVT-01 汛期模拟（约 20 s 时序）**
- 触发：事件面板"启动汛期演练"（红色按钮）；栏杆点位切到汛期只做水位，不触发灾害流程。
- t0：顶部红色预警横幅"汛期水位上涨，请远离河道" + 提示音；可手动关闭横幅，但不中断流程。
- t0–12 s：水位 0 → +2.40 m，流速 0.8 → 2.5 m/s，水色变浑，漫滩注水，水位尺上升。
- t12 s：栏杆警示灯转红，步道入口两处动态挡板落下，播放广播音效。
- t15 s：弹窗列影响范围（滨河步道 / 亲水平台 / 绿心湿地）与"预计 15 min（演示）"。
- 恢复：点击"结束演练"，20 s 回落，预警解除，挡板升起，灯回黄。
- 边界：可与任意天气 / 时间组合（雨夜 + 汛期为推荐氛围）；水位用材质位移实现，不做流体模拟。

**EVT-02 夜景模式一键切换**
- 触发：UI"夜景模式"按钮。
- 时序：时间先切到夜晚（2.5 s）→ 各区建筑内透由近及远依次点亮（每栋错峰 0.1 s）→ 桥体灯带、科创大楼顶部霓虹 0.3 s 淡入 → 路灯全亮（80%）→ 车灯开启。
- 反向：再按一次，依次熄灭，回到切换前的时间。
- 与 ENV-01"夜晚"的区别：夜晚是时间状态，夜景模式是带顺序动画的演出；UI 上并列，会强制时间 = 夜晚。
- 冲突：手动关掉的路灯保持关闭，退出时恢复到显式设置。

## 2.5 冲突与组合规则

| 场景 | 规则 |
|---|---|
| 弹窗与相机跳转 | 跳转时关闭弹窗；弹窗打开时仍可移动 |
| 夜景模式与手控灯 | 事件只覆盖未被手动修改的灯 |
| 汛期与天气 | 可叠加；雨夜 + 汛期提示为推荐组合 |
| 雨夜预设与手动改天气 | 手动改天气后，时间显示"夜晚（自定义）" |
| 汛期与栏杆点位 | 共享状态机；流程中只允许恢复常态 |
| 低配模式 | 关体积云、雨粒子减半、车流降档 |
