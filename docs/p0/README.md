# P0 灰盒坐标包

P0 的目标是**不依赖任何精模**先把交互骨架和空间关系跑通。本目录把设计文档里的分区、路网、桥位、建筑体块、相机点位固化成可导入的数据。

## 坐标约定

- CSV 内单位**米**；导入 UE 时 ×100 得厘米。
- **+X 东、+Y 北、+Z 上**（UE 世界坐标；yaw 0 时朝向 +X）。
- 原点 `(0,0,0)` = **跨河大桥中心线 × 北岸滨河大道（R1）中心线**的交点。
- `EL 0.00` = 河流常水位；表中 Z 一律为海拔高度，不是离地高度。
- 台地高度：A 4.0 / B 3.5 / C 2.2 / D 2.8 / F 4.0 m。
- 城市范围：X ∈ [-2100, 2100]，Y ∈ [-1500, 1500]（4.2 × 3.0 km）。

## 文件

| 文件 | 内容 |
|---|---|
| `zones.csv` | 7 个分区矩形：A 科创园区 / B 滨河居住区 / C 中央绿心 / D 市政广场 / F 高速出入口 / G-N 北山 / G-S 南山 |
| `roads.csv` | 4 条主路（R1–R4）+ 跨河大桥（B1）中心线折线，逐点 X / Y / EL，含宽度 |
| `buildings.csv` | 12 栋体块：中心、占地、高度、层数、朝向 |
| `cameras.csv` | CAM-02 三个鸟瞰预设、CAM-03 三个跳转点位、漫游起点 |
| `markers.csv` | OBJ-01～04 四个交互锚点 |
| `import_blockout.py` | 可选：UE5 编辑器 Python 一键摆盒并打 tag |

## 导入

1. **手动**：新建关卡 `L_P0_Blockout`，按表摆 Cube（100 cm 基础体，缩放即米）。建议在 World Outliner 里按 Zone / Building / Road 分文件夹。
2. **脚本**：
   - 把本目录拷到本机，例如 `D:/City/P0`；
   - 打开 UE5 编辑器 → Output Log → 下拉切到 **Python**；
   - 执行 `exec(open(r"D:/City/P0/import_blockout.py").read())`，或设环境变量 `P0_DIR` 后 Execute Python Script。
   - 脚本会生成带标签的 StaticMeshActor，tag 分组：`P0_Zone` / `P0_Building` / `P0_Road` / `P0_Camera` / `P0_Marker`。
   - 脚本在 UE 5.4 的 Python API 下编写，未在本机编辑器验证；若个别 API 报错，按错误行调整（常见差异在 `spawn_actor_from_class` 与 CameraComponent 的正交属性）。
 3. **DataTable**：做交互框架时，把 `buildings.csv` 映射到同名结构体即可直接导入为 `DT_Buildings`。

## 预览（不用装 UE5）

- `preview.html`：单文件矢量预览，双击用浏览器打开即可，离线、无依赖。平面 / 轴测两个视图，滚轮缩放、拖动平移、双击复位；点建筑体块或 ★ 锚点，右侧显示该交互节点的触发方式与反馈。
  - `preview.html#axo` 直接打开轴测图；`preview.html#node=OBJ-01` 直接选中某个节点。
- `preview_plan.png`、`preview_iso.png`：同一套数据的静态图，适合贴进汇报或聊天。
- 重新生成：`python3 build_preview_html.py`（只用 Python 3 标准库）；`python3 render_preview.py`（需要 matplotlib，仅生成 PNG）。配色和几何定义在 `p0_common.py`，两个脚本共用。


## 与设计文档的差异（P0 简化）

- **CAM-02 全城预设改用正交相机**：透视相机在 EL +600 m、俯角 75° 下只能覆盖约 700 m 宽，拍不全 4.2 km；正交 `OrthoWidth 4600` 才能一屏看全城。设计文档 §2.1 已同步更新。
- **桥的纵断面是折线**：北引道 EL 3.2→16（约 6.4% 坡）、主跨平段 280 m、南引道对称回落；真实竖曲线留到 P1。
- **山体只给参考矩形**：G-N / G-S 的 `SurfaceEL` 是台地基准，峰顶（+220 / 观景台 +145）留给地形高度图。
- **道路用平板**：厚度统一 0.4 m，不做路缘、标线、人行道；P1 起替换为道路套件。
- 桥面与南北滨河大道是**立体交叉**（桥下净空约 12.8 m），不是平面路口。
